WorkSet v2.7.19 native password autofill

Sign-in email now uses username autofill hints; passwords use current-password, signup/reset new-password. Android WebView is explicitly marked autofillable. After successful Supabase login, local native plugin completes the OS AutofillManager context without receiving the user's password. The Android autofill provider decides whether to offer a save prompt, and website credentials will not necessarily match the APK: no verified site-app Digital Asset Links association exists for the GitHub Pages project URL and test signing key.

Supabase already persists the session, except after uninstall, storage clear, signout, or invalid credentials. Test saved passwords via Android Settings > Passwords, passkeys and autofill and then by signing in and focusing fields. Do not send passwords or recordings containing secrets. Web/PWA branding and layout unchanged.
